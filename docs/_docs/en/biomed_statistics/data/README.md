# Teaching dataset

`biomedical_demo.csv` is a simulated dataset created only to make the bookdown project self-contained because the Excel workbook referenced in the supplied R Markdown files was not included among the uploads.

It contains no real participants and should not be used for scientific conclusions.

The structure mirrors variables used in the source practicals: treatment, demographics, baseline severity, baseline/week-12 SBP, CRP, biomarker, quality of life, adherence, clinical response, adverse events, a sampling weight, and a simple 90-day time-to-event example.
