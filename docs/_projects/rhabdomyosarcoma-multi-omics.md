Conducted network-based analysis to map subtype-specific molecular features in
rhabdomyosarcoma using metabolomic and proteomic profiles.
I applied WGCNA to define co-expressed protein modules, used eigengene-based
Wilcoxon testing to distinguish clinical subtypes, constructed protein-protein
interaction networks, and applied centrality analysis to prioritize regulatory
drivers.
